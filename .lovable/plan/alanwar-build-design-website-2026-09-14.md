# ALANWAR Build & Design Website

## Public website
- Build a premium single-page business experience with a cinematic opening-door introduction, sticky navigation, and clear call, WhatsApp, consultation, and enquiry actions.
- Use the official logo and Anwar Basha A’s uploaded portrait, with a restrained cream, charcoal, navy, and gold visual system.
- Add About, three distinct animated service presentations, Projects, Reviews, enquiry, final contact, and footer sections.
- Use one supplied phone number for every service. Omit service-area and social claims until real details are supplied.

## Projects and reviews
- Create touch-friendly Projects and Reviews carousels showing exactly three items on desktop and one on mobile, advancing one item at a time with autoplay, controls, pause-on-hover, and swipe.
- Add a full-screen project lightbox with previous, next, close, keyboard, and swipe controls.
- Add a customer review form with 1–5 star input and optional photo. New reviews stay pending until approved.

## Secure management area
- Add secure email/password admin sign-in and protected management pages.
- Keep admin authorization in a dedicated roles table and validate it for every protected action.
- Provide project upload, multi-upload, preview, replace, reorder, and delete controls.
- Provide pending, approved, and rejected review views with approve, reject, edit, and delete actions.
- Provide a private enquiry inbox with submitted service, message, and timestamp.
- Keep the footer Admin link deliberately subtle.

## Data and storage
- Store projects, moderated reviews, enquiries, and admin roles in Lovable Cloud with strict access policies.
- Use managed image storage for project and review uploads, with file type and size validation.
- Include no fake projects or reviews; empty states will invite real content.

## Quality and discoverability
- Add route metadata, Open Graph fields, LocalBusiness/Service structured data using only known facts, semantic headings, descriptive image text, and a logo-based favicon.
- Respect reduced-motion preferences and optimize images, lazy loading, and animation transforms.
- Verify desktop, tablet, and mobile layouts; navigation; call/WhatsApp links; forms; carousels; lightbox; sign-in; moderation; uploads; deletion; enquiries; and overflow.

## Remaining input
- The real admin email is required to create the initial admin account. Until supplied, the secure login page and management area can be completed, but account creation remains pending.
